# ASPortfolio

Portfolio mot trang, nen toi, cua Anh Son - frontend developer intern tai GDT Tech.

- React, Next.js, TypeScript, Tailwind CSS, GSAP, Framer Motion, hls.js
- Du an: AniMan Admin Panel, OrderTower Dashboard, AniMan Manga Studio, Freelance Dashboard
- Lien he: GitHub https://github.com/asotaku205, Upwork, Freelancer.com

## Chay thu

Mo truc tiep file `index.html` bang trinh duyet, hoac chay bang may chu tinh bat ky, vi du:

```bash
npx serve .
```

## Deploy len GitHub Pages

Vao Settings -> Pages, chon Deploy from a branch, branch main, thu muc root. Trang se chay o `https://asotaku205.github.io/ASPortfolio/`.
